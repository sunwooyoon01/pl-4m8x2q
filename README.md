# productivity log

Free hosting on GitHub Pages. These files contain no personal data; everything you enter stays in your browser.

1. New repository with a random name (e.g. pl-4m8x2q), set to Public.
2. Upload every file in this folder so index.html sits at the top level.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://YOURNAME.github.io/REPO/ in Safari on iPhone (or Chrome/Edge on desktop).
5. iPhone: Share > Add to Home Screen. Desktop Chrome/Edge: install icon in the address bar.

Back up from the Backup tab now and then. Deleting the home screen icon deletes its saved data.
